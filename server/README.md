# Сервер профилей и синхронизации (Google Таблица)

Профили и облачные копии данных (ДЗ, правки расписания, настройки, файл расписания) хранятся в вашей Google Таблице. Ей управляет код Apps Script из файла [`Code.gs`](Code.gs). Бесплатно, без своего сервера.

## Установка (5 минут, делается один раз)

1. Откройте [sheets.new](https://sheets.new) и создайте пустую таблицу. Назовите её, например, «КГМУ расписание — сервер».
2. В меню выберите **Расширения → Apps Script**.
3. Удалите всё в редакторе, вставьте целиком содержимое `Code.gs` и нажмите 💾 **Сохранить**.
4. Нажмите **Начать развертывание → Новое развертывание**.
   - Слева у пункта «Выберите тип» нажмите ⚙ и выберите **Веб-приложение**.
   - **Запуск от имени:** «Я».
   - **У кого есть доступ:** «Все».
   - Нажмите **Развернуть**.
5. Google попросит разрешение. Нажмите **Предоставить доступ** и выберите свой аккаунт. Появится предупреждение «Приложение не проверено»: нажмите **Дополнительные настройки → Перейти на страницу…** и **Разрешить**. Скрипт работает только с этой таблицей.
6. Скопируйте **URL веб-приложения**, он заканчивается на `/exec`.

## Подключение приложения и сайта

- **Android:** Настройки → Профиль → «Сервер» → вставьте ссылку → «Сохранить и проверить».
- **Сайт:** то же самое в Настройки → Профиль. Можно вписать ссылку в `web/index.html` в строку `const DEFAULT_SERVER = '';`, и тогда её не придётся вводить никому.
- В Android-приложении ссылку можно встроить так же: `CloudState.DEFAULT_SERVER`.

Если вписать ссылку в `DEFAULT_SERVER`, пользователям не придётся вводить её вручную: достаточно создать профиль.

## Как это устроено

| Лист | Что хранит |
|---|---|
| Users | профили: юзернейм, полное имя, группа, аватар, хеш пароля (сам пароль не хранится) |
| Sessions | токены входа на устройствах |
| Backups | облачные копии ДЗ, правок, настроек и файла расписания (по 40 000 символов в строке) |

Листы создаются сами при первом запросе.

- **Профиль.** Чтобы создать профиль, нужны полное имя (имя и фамилия), юзернейм и пароль. Юзернейм пользователь придумывает сам: 3–24 символа, латиница, цифры, `_` и `.`. Юзернейм уникален, регистр букв не важен. Вход выполняется по юзернейму и паролю.
- **Перенос.** Войдите под тем же юзернеймом на другом телефоне или на сайте. Приложение предложит загрузить копию, и всё перенесётся, включая файл расписания.
- **Обновление кода.** Вставьте новый `Code.gs`, затем откройте **Начать развертывание → Управление развертываниями**, нажмите ✏, выберите **Версия: новая** и нажмите **Развернуть**. Ссылка останется прежней.
