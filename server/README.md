# Сервер для профиля и «Моей группы» (Google Таблица)

Все данные профилей, облачные копии, объявления, общие ДЗ и пропуски хранятся в одной Google Таблице. Ей управляет код Apps Script из файла [`Code.gs`](Code.gs). Бесплатно, без своего сервера.

## Установка (5 минут, делается один раз)

1. Откройте [sheets.new](https://sheets.new) и создайте пустую таблицу. Назовите её, например, «КГМУ расписание — сервер».
2. В меню выберите **Расширения → Apps Script**.
3. Удалите всё в редакторе, вставьте целиком содержимое `Code.gs` и нажмите 💾 **Сохранить**.
4. Нажмите **Начать развертывание → Новое развертывание**.
   - Слева у пункта «Выберите тип» нажмите ⚙ и выберите **Веб-приложение**.
   - **Запуск от имени:** «Я».
   - **У кого есть доступ:** «Все».
   - Нажмите **Развернуть**.
5. Google попросит разрешение. Нажмите **Предоставить доступ** и выберите свой аккаунт. Появится предупреждение «Приложение не проверено»: нажмите **Дополнительные настройки → Перейти на страницу…** и **Разрешить**. Скрипт работает только с этой таблицей.
6. Скопируйте **URL веб-приложения**, он заканчивается на `/exec`.

## Подключение приложения и сайта

- **Android:** Настройки → Профиль → «Сервер» → вставьте ссылку → «Сохранить и проверить».
- **Сайт:** то же самое в Настройки → Профиль. Можно вписать ссылку в `web/index.html` в строку `const DEFAULT_SERVER = '';`, и тогда её не придётся вводить никому.
- В Android-приложении ссылку можно встроить так же: `CloudState.DEFAULT_SERVER`.

Дайте ссылку одногруппникам. Все, кто подключится к одному серверу и выберет одну группу, окажутся в одной «Моей группе».

## Как это устроено

| Лист | Что хранит |
|---|---|
| Users | профили: группа, имя, аватар, контакт, роль, хеш пароля (сам пароль не хранится) |
| Sessions | токены входа на устройствах |
| Backups | облачные копии ДЗ, правок, настроек и файла расписания (по 40 000 символов в строке) |
| Homework | общие ДЗ группы |
| News | объявления и переносы пар |
| Attendance | пропуски и отработки |

Листы создаются сами при первом запросе.

- **Роли.** Первый зарегистрированный в группе становится **старостой**. Староста может назначить **заместителя**, передать свою роль или удалить участника. Объявления публикуют староста и заместитель. Общие ДЗ может добавлять любой. Пропуски каждый видит только свои, а староста и заместитель видят пропуски всей группы.
- **Ручная правка.** Таблицу можно править вручную, например поменять роль в столбце `role`: `starosta`, `deputy` или `member`.
- **Обновление кода.** Вставьте новый `Code.gs`, затем откройте **Начать развертывание → Управление развертываниями**, нажмите ✏ у текущего развертывания, выберите **Версия: новая** и нажмите **Развернуть**. Ссылка останется прежней.

## Проверка без Google

```bash
node server/test/api.test.cjs          # тесты логики сервера

```
