# Neon Расписание

Android-приложение в неоновом стиле. Оно читает файл расписания учебного отдела (`.xlsx`) и показывает занятия вашей группы списком: с часами, таймерами и домашними заданиями.

## Возможности

- **Сегодня**: большие часы, дата, номер недели (1/2), карточка «сейчас идёт / следующая пара» с обратным отсчётом и прогрессом. Учитываются перерывы внутри пары (например, 10:40–12:10, 12:20–13:05). Ниже список пар на сегодня и на следующий учебный день.
- **Неделя**: листание недель, выбор дня, у каждого дня показано число пар.
- **ДЗ**: нажмите на пару, введите задание, и оно привяжется **к следующей паре по этому предмету**. Можно привязать и к текущей паре. Во вкладке «ДЗ» задания разделены на предстоящие, просроченные и выполненные, у каждого показано, сколько осталось до пары.
- **Ещё**: смена группы, загрузка нового файла расписания, таблица кафедр и форм аттестации.
- Файл `.xlsx` можно открыть прямо из Telegram или из проводника через «Открыть с помощью → Neon Расписание».

## Как разбирается расписание

Парсер (`app/src/main/java/.../data/ScheduleParser.kt`) понимает такой «свободный» формат ячеек:

| В ячейке | Как понимается |
|---|---|
| `10.40-12.10, 12.20-13.05 Фармакология 07.09-28.12` | каждую неделю в этот день недели в указанном диапазоне дат |
| `Общая хирургия 2 неделя по 30.12` | через неделю, по второй неделе, с начала семестра до 30.12 |
| `ЛЕКЦИЯ ГИГИЕНА 1 неделя 01.09-онлайн, 15.09, 29.09…` | лекция в перечисленные даты, 01.09 проходит онлайн |
| `… 02.12, 16.12-11.50-13.20` | 16.12 занятие проходит в другое время |
| `… 09.12, 9.30-11.00-16.12` | то же самое, когда время записано перед датой |
| ячейка, объединённая на все группы | общее занятие для всего потока |

Чередование недель берётся из строки «1 неделя - … 2 неделя - …». Места проведения берутся из текста ячейки или из таблицы кафедр внизу листа.

## Сборка APK

APK собирается автоматически в GitHub Actions (`.github/workflows/build-apk.yml`) при каждом push. Готовый `NeonRaspisanie.apk` появляется в разделе **Releases** репозитория, а также в артефактах сборки.

Локальная сборка (нужны JDK 17 и Android SDK):

```bash
./gradlew assembleRelease
# app/build/outputs/apk/release/app-release.apk
```
